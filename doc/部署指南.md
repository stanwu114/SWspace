# AI员工协作系统 - 部署指南

## 系统要求

### 硬件要求
- CPU: 4核心以上
- 内存: 8GB以上 (推荐16GB)
- 硬盘: 20GB以上可用空间

### 软件要求
- Java 17+
- Node.js 18+
- PostgreSQL 16+ (带pgvector扩展)
- Docker (可选，用于容器化部署)

## 快速开始

### 1. 数据库配置

#### 使用Docker (推荐)
```bash
# 启动PostgreSQL容器
docker run -d \
  --name aispace-postgres \
  -p 5433:5432 \
  -e POSTGRES_USER=qoder \
  -e POSTGRES_PASSWORD=qoder_password \
  -e POSTGRES_DB=aispace_db \
  pgvector/pgvector:pg16

# 启用pgvector扩展
docker exec -it aispace-postgres psql -U qoder -d aispace_db -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

#### 手动安装
1. 安装PostgreSQL 16
2. 安装pgvector扩展
3. 创建数据库和用户

```sql
CREATE DATABASE aispace_db;
CREATE USER qoder WITH PASSWORD 'qoder_password';
GRANT ALL PRIVILEGES ON DATABASE aispace_db TO qoder;
\c aispace_db
CREATE EXTENSION IF NOT EXISTS vector;
```

### 2. 后端部署

```bash
cd backend

# 配置环境变量（或修改application.yml）
export JAVA_HOME=/path/to/java17

# 编译
mvn clean compile

# 运行
mvn spring-boot:run
```

后端将启动在 http://localhost:8080

### 3. 前端部署

```bash
cd frontend

# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build
```

## 配置说明

### application.yml 主要配置项

```yaml
# 数据库连接
spring:
  datasource:
    url: jdbc:postgresql://localhost:5433/aispace_db
    username: qoder
    password: qoder_password

# AI模型配置
ai:
  openai:
    api-key: your-api-key
    base-url: https://api.moonshot.cn/v1  # 或其他兼容API
    model: kimi-k2-0711-preview

# 通知服务配置
notification:
  feishu:
    webhook-url: ${FEISHU_WEBHOOK_URL:}
  telegram:
    bot-token: ${TELEGRAM_BOT_TOKEN:}
    chat-id: ${TELEGRAM_CHAT_ID:}
```

### 环境变量

| 变量名 | 说明 | 必填 |
|--------|------|------|
| OPENAI_API_KEY | AI模型API密钥 | 是 |
| FEISHU_WEBHOOK_URL | 飞书机器人Webhook | 否 |
| TELEGRAM_BOT_TOKEN | Telegram Bot Token | 否 |
| TELEGRAM_CHAT_ID | Telegram Chat ID | 否 |
| ENCRYPTION_KEY | 数据加密密钥 | 否 |

## 备份与恢复

### 自动备份
系统每天凌晨2点自动执行数据库备份，备份保留30天。

### 手动备份
```bash
curl -X POST http://localhost:8080/api/v1/system/backup
```

### 备份位置
默认: `~/.aiworker/backups/`

## 故障排除

### 常见问题

1. **数据库连接失败**
   - 检查PostgreSQL是否运行
   - 确认端口和凭据正确
   - 检查pgvector扩展是否已安装

2. **AI模型调用失败**
   - 验证API密钥有效性
   - 检查网络连接
   - 确认模型名称正确

3. **前端无法连接后端**
   - 确认后端已启动
   - 检查CORS配置
   - 确认端口未被占用
