# AI员工协作系统 - 使用指南

## 系统概述

AI员工协作系统是一款面向政企行业的智能办公助手，集成了四个专业AI Agent：
- **情报分析师** - 招标文件解读、政策分析
- **文档写手** - 方案生成、标书编写
- **客户助理** - 纪要整理、跟进建议
- **知识管家** - 知识提取、语义搜索

## 功能模块

### 1. 工作台 (Dashboard)

工作台提供系统整体视图，包括：
- 项目统计
- 今日提醒
- 快捷操作入口
- 最近活动

### 2. 项目空间

#### 创建项目
1. 点击"新建项目"
2. 填写项目基本信息（名称、客户、预算等）
3. 设置项目状态和阶段
4. 保存

#### 项目看板
项目按状态分为：
- 线索 (LEAD)
- 机会 (OPPORTUNITY)
- 执行 (EXECUTION)
- 完成 (COMPLETED)

### 3. 客户空间

#### 客户管理
- 创建客户档案
- 添加联系人
- 记录沟通历史
- 设置跟进提醒

#### 联系人管理
每个客户可添加多个联系人，包含：
- 姓名、职位
- 联系方式
- 决策角色

### 4. 招标监控

#### 功能说明
系统自动监控配置的招标平台，根据关键词匹配推送相关招标信息。

#### 配置监控关键词
设置 -> 招标监控 -> 关键词配置

#### 查看招标信息
- 全部信息
- 已匹配（符合关键词的）
- 已收藏
- 未读

### 5. 案例库

#### 创建案例
从已完成的项目中提炼案例，包含：
- 项目背景
- 挑战与问题
- 解决方案
- 实施成果
- 经验教训

#### 案例发布
案例需经审核后发布，发布后可被其他用户搜索和引用。

### 6. 知识库

#### 知识分类
- 行业知识
- 方案知识
- 案例
- 销售技巧
- 经验教训
- 模板

#### 知识检索
支持关键词搜索和语义搜索，可按分类筛选。

### 7. AI对话

#### 选择Agent
点击顶部Agent切换按钮，选择对应的AI助手：

| Agent | 颜色 | 能力 |
|-------|------|------|
| 情报分析师 | 蓝色 | 招标解读、政策分析、竞品分析 |
| 文档写手 | 紫色 | 方案撰写、标书编写、PPT大纲 |
| 客户助理 | 绿色 | 纪要整理、跟进建议、关系分析 |
| 知识管家 | 橙色 | 知识提取、语义搜索、知识推荐 |

#### 对话示例

**情报分析师**
```
用户: 请帮我分析这份招标文件的关键要求
AI: 好的，请上传招标文件或粘贴内容...
```

**文档写手**
```
用户: 请帮我写一个智慧城市项目的技术方案大纲
AI: 我来为您生成智慧城市项目技术方案大纲...
```

**客户助理**
```
用户: 帮我整理今天和XX局的会议纪要
AI: 请提供会议记录内容，我来帮您整理...
```

### 8. 设置

#### 个人信息
配置用户名、角色等基本信息。

#### API配置
配置AI模型API Key：
- OpenAI / Kimi / DeepSeek 等

#### 通知设置
- 桌面通知
- 飞书推送
- Telegram推送

#### 数据管理
- 查看数据存储位置
- 执行数据备份
- 清理缓存

## 快捷操作

| 快捷键 | 功能 |
|--------|------|

| Ctrl/Cmd + K | 全局搜索 |

## 最佳实践

### 项目管理
1. 及时更新项目状态
2. 记录关键里程碑
3. 关联相关文档和客户

### 客户跟进
1. 每次沟通后及时记录
2. 设置提醒避免遗漏
3. 定期分析客户健康度

### 知识沉淀
1. 项目结束后及时总结
2. 提取可复用的方案片段
3. 记录经验教训

## 常见问题

### Q: AI回复很慢怎么办？
A: AI响应时间取决于模型和网络。可尝试：
- 检查网络连接
- 更换AI模型
- 简化问题描述

### Q: 如何导出文档？
A: 在文档详情页点击导出按钮，支持导出为：
- Word (.docx)
- PDF
- Markdown

### Q: 数据如何备份？
A: 系统每日自动备份。手动备份：
设置 -> 数据管理 -> 立即备份
